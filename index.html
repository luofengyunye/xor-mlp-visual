输出层权重按隐藏激活 h 加权；隐藏层梯度再乘 sigmoid 导数 h(1−h)，这是误差向输入方向传播的链式法则。

Adam 对每个参数维护一阶、二阶动量，并做偏差修正。此处学习率 0.08，β₁=0.9，β₂=0.999。

01 / COLOR

热力颜色是输出概率

青色倾向类别 0，橙色倾向类别 1；越鲜艳表示模型越有把握。

02 / CONTOURS

隐藏神经元先改变坐标

h₁、h₂ 把原来的 x₁、x₂ 投影到两个一维激活轴上；输出层再对它们做加权组合。

03 / BOUNDARY

白线来自 logit = 0

σ(z)=0.5 等价于 z=0。隐藏层 sigmoid 让这条边界可以弯曲成 XOR 所需的对角结构。
